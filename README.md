# チャート道場

実在する日本株のチャートを見て、次の値動き（翌日 / 3日後 / 5日後）を「上がる」か「下がる」かで予想し、答え合わせと解説で振り返るチャート読みトレーニングツールです。

**公開URL:** https://shihooow.github.io/chart-dojo/

## できること

- 実在する日本株（下記ウォッチリスト）の実際の値動きを使って出題
- 出来高・取引代金(概算)・RSI(14)・ボリンジャーバンド(±2σ)・短期トレンド(SMA)をセットで表示
- 正答率、連続正解数、最高連続記録を記録(ブラウザのlocalStorageに保存。端末ごと)
- 予想が当たった/外れた場合の両方について、指標に基づいた解説を自動生成

投資助言ではなく、あくまでチャートを読む練習のためのツールです。

## データについて

`data.json` に、Yahoo!ファイナンスから実際に取得した個別銘柄の日足OHLCV(始値・高値・安値・終値・出来高)を保存しています。

- 初回: 2026-09-07に、ウォッチリスト15銘柄それぞれについて直近20営業日分を一括取得(シード)。
- 以降: 平日朝、自動化タスクが当日分の最新データを取得して`data.json`に追記していきます(既存の日付は上書きしません)。時間とともに、1銘柄あたりの実データの本数が増えていきます。

取引代金は「終値×出来高」による概算値です(実際の売買代金とは若干異なる場合があります)。信用残(信用取引残高)は無料データソースでは安定して取得できないため、今回は対象外にしています。

## ファイル構成

- `index.html` — アプリ本体(データはdata.jsonをfetchして読み込み)
- `data.json` — 実データ本体
- `watchlist.json` — 対象銘柄一覧(証券コード・銘柄名)
- `scripts/append_data.py` — 新しく取得した日足データをdata.jsonに追記するスクリプト

## 自動更新の仕組み

「chart-dojo データ更新」という自動化タスクが平日朝に以下を行います:

1. `watchlist.json`の各銘柄について、`https://finance.yahoo.co.jp/quote/<証券コード>.T/history` から直近の日足データを取得
2. 新しい日付の行だけを `scripts/append_data.py` で `data.json` に追記
3. `git add -A && git commit && git push`
