# チャート道場

実在する日本株のチャートを見て、次の値動き（翌日 / 3日後 / 5日後、週足なら翌週 / 3週間後 / 5週間後、月足なら翌月 / 3ヶ月後 / 5ヶ月後）を「上がる」か「下がる」かで予想し、答え合わせと解説で振り返るチャート読みトレーニングツールです。

**公開URL:** https://shihooow.github.io/chart-dojo/

## できること

- 実在する日本株（下記ウォッチリスト）の実際の値動きを使って出題
- 日足・週足・月足を切り替えて出題（時間軸ごとに情報量や値動きの見え方が変わる練習ができます）
- 出来高・取引代金(概算)・RSI(14)・ボリンジャーバンド(±2σ)・SMA5・MACDをチャート上に直接表示
- 正答率、連続正解数、最高連続記録を記録(ブラウザのlocalStorageに保存。端末ごと)
- 予想が当たった/外れた場合の両方について、指標に基づいた解説を自動生成
- 回答するたびに出題履歴を記録し、10問ごとに1問、過去に間違えたまま(直近の挑戦が不正解)のチャートを復習として再出題(チャートに「復習」バッジを表示)
- 「レポートを見る」ボタンから、RSI・トレンド・ボリンジャーバンド・MACD・値動きの形・時間軸ごとの正答率や、間違えやすい銘柄をいつでも確認可能

投資助言ではなく、あくまでチャートを読む練習のためのツールです。

## データについて

`data.json` に、Yahoo!ファイナンスから実際に取得した個別銘柄のOHLCV(始値・高値・安値・終値・出来高)を、銘柄ごとに `daily`(日足)・`weekly`(週足)・`monthly`(月足)の3系統で保存しています。

- 初回シード: 2026-09-07に、ウォッチリスト15銘柄それぞれについて、日足は直近20営業日分、週足は直近20週分、月足は直近20ヶ月分を一括取得。
- 以降(日足): 平日朝、自動化タスクがYahoo!ファイナンスから当日分の最新日足データを取得して`data.json`に追記していきます(既存の日付は上書きしません)。時間とともに、1銘柄あたりの日足データの本数が増えていきます。
- 以降(週足・月足): 別途取得はせず、蓄積された日足データから自動集計して更新します(`scripts/append_data.py`が日足の追記と同時に実行)。日足のカバー範囲に含まれる週・月の足は、その時点の日足から再計算した値に更新され、範囲外(初回シードでのみ存在する古い期間)はそのまま保持されます。

取引代金は「終値×出来高」による概算値です(実際の売買代金とは若干異なる場合があります)。信用残(信用取引残高)は、ブラウザでは無料閲覧できるものの、自動取得の仕組み(WebFetch)経由では安定して取得できなかったため、今回は対象外にしています。

## 出題履歴・復習・レポートについて

- 出題履歴(`chartDojoHistory`)もブラウザのlocalStorageに保存されます(端末ごと、最大300件)。正答率などの記録と同様、サーバー側には送信されません。
- 「復習」は、同一の問題(銘柄・時間軸・予想期間・出題時点の組み合わせ)について直近の挑戦が不正解だったものを対象に、10問に1問の頻度で再出題します。正解すればその問題は復習対象から外れます。
- 「レポートを見る」ボタンでは、記録が3件以上たまった項目について、RSI・短期トレンド(SMA)・ボリンジャーバンド・MACD・値動きの形・時間軸ごとの正答率と、間違えやすい銘柄の一覧を表示します。

## ファイル構成

- `index.html` — アプリ本体(データはdata.jsonをfetchして読み込み)
- `data.json` — 実データ本体(銘柄ごとに daily / weekly / monthly)
- `watchlist.json` — 対象銘柄一覧(証券コード・銘柄名)
- `scripts/append_data.py` — 新しく取得した日足データをdata.jsonに追記し、週足・月足を自動集計するスクリプト
- `scripts/seed_initial_data.py` — 初回シード(日足)に使ったスクリプト(参照用)
- `scripts/seed_weekly_monthly.py` — 初回シード(週足・月足)に使ったスクリプト(参照用)

## 自動更新の仕組み

「chart-dojo データ更新」という自動化タスクが平日朝に以下を行います:

1. `watchlist.json`の各銘柄について、`https://finance.yahoo.co.jp/quote/<証券コード>.T/history` から直近の日足データを取得
2. 新しい日付の行だけを `scripts/append_data.py` で `data.json` に追記(このとき週足・月足も日足から自動集計され更新される)
3. `git add -A && git commit && git push`
